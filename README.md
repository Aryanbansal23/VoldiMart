# 🛒 VoldiMart

A modern full-stack e-commerce web application built using the **MERN Stack**. VoldiMart provides a smooth shopping experience with product browsing, search, authentication, cart management, personalized recommendations, and a responsive modern UI.

## ✨ Features

### 🛍️ Shopping Experience
- Browse products
- Product search functionality
- Product categories
- Featured products
- New arrivals
- Product details page
- Add products to cart
- Cart quantity management
- Personalized product recommendations

### 🔐 Authentication
- User registration
- User login
- JWT authentication
- Protected routes
- Secure user sessions

### 🎨 Modern UI
- Fully responsive design
- Material UI components
- Modern animations and transitions
- Interactive navigation bar
- Responsive footer
- Product cards
- Search suggestions
- Notifications and alerts

### ⚙️ Backend Features
- RESTful API
- MongoDB database
- Express.js server
- JWT authentication
- Product management
- User management
- Recommendation system
- API retry handling

---

## 🛠️ Tech Stack

### Frontend

- React.js
- Material UI (MUI)
- React Router
- Axios
- JavaScript

### Backend

- Node.js
- Express.js
- MongoDB
